# AR/VR: from zero to my own headset

I'm a complete beginner learning augmented and virtual reality in public. The end goal is to understand how headsets work and build my own. This repo is my proof of work: notes, demos and a build log.

**Device:** Android phone (Android 16). **Budget:** low, mostly free tools.

## Roadmap

- [ ] 01 Web 3D basics (HTML, JavaScript, A-Frame, three.js)
- [ ] 02 Phone VR: gyroscope-driven 360 viewer, stereo view
- [ ] 03 WebXR AR on my phone: place objects in my room
- [ ] 04 DIY phone-in-viewer headset (lenses + housing + distortion)
- [ ] 05 Own head tracking: ESP32 + IMU + sensor fusion
- [ ] 06 Tethered headset experiments (OpenXR / Monado)
- [ ] 07 AR optics and SLAM study
